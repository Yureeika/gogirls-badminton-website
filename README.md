
# GoGirls – Women's Badminton Club Website

## About the Project

GoGirls is a multi-page website developed as an academic web development project for a women's badminton club. The website is designed to provide information about the club, its activities, programs, events, coaching team, and membership opportunities.

The project focuses on creating an informative, interactive, and user-friendly website using fundamental front-end web development technologies.

## Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript** – Interactive features and website functionality.
- **Notepad++** – Code editor used for development.

## Website Features

- **Homepage:** Introduction to the club with an image slideshow and event countdown.
- **About Us:** Information about the badminton club.
- **Programs:** Details about available badminton programs.
- **Events:** Information about club events and activities.
- **Team:** Introduction to club members and team information.
- **Coaches:** Information about coaching staff.
- **Membership:** Membership information and opportunities.
- **Gallery:** Image gallery with an interactive lightbox.
- **Contact:** Contact information and contact form.
- **FAQ:** Frequently asked questions.
- **Join Us:** Membership registration interface.
- **Resources:** Useful badminton-related resources.
- **Privacy:** Privacy information.
- **Interactive Chatbot:** A chatbot interface for website visitors.
